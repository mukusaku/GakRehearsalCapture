# GakRehearsalCapture
学のリハーサル結果をOCRで読み取ってCSVに吐くやつ

## 使い方

1. `GakRehearsalCapture.exe` を起動します
2. **範囲を選択** をクリックしてリハーサル結果のスコア部分をドラッグで囲みます。選んだ領域がプレビューに表示されます
3. 自動でOCRが実行され、ラベルに読み取った数字が表示されます。何も表示されない場合は読み取りに失敗しています
4. 数字を確認したら **CSV保存** を押してください。結果はアプリと同じフォルダにある `output.csv` に追記されます
5. 同じ範囲で再度キャプチャしたいときは **今の選択範囲で読み取り直す** を使うと、再度キャプチャして即座にOCRを行います

## 仕様

スコアの読み取りは以下のロジックで実装しています。
そのため3桁のスコアや1ステージの編成が2人以下の場合の読み取りをサポートしていません。
1. 選択範囲全体をOCR
2. カンマ付きの4~6桁の数字が3つ並んでいるパターンを正規表現で抽出
4. カンマでセル分割されないようダブルクォートで囲み、改行コードで繋ぐ
5. csvに書き込み
